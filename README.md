🌌 ¿Qué es Asteroide?

Asteroide es una aplicación web interactiva dedicada a la exploración de asteroides y objetos cercanos a la Tierra.

El proyecto está conectado con la API oficial de la NASA, por lo que la información mostrada procede de los servicios de datos de la NASA.

🛰️ Los datos no son simplemente información inventada o estática: la aplicación consulta los servicios de la NASA para obtener información sobre los objetos espaciales.

🛰️ Conectado con la NASA

Este proyecto utiliza las NASA Open APIs para acceder a información proporcionada por la NASA.

<div align="center"> <a href="https://api.nasa.gov/"> <img src="https://img.shields.io/badge/🔭_NASA_OPEN_APIs-E03C31?style=for-the-badge" alt="NASA Open APIs"> </a> </div>

La utilización de esta API permite que la aplicación pueda trabajar con información procedente de los servicios oficiales de la NASA.

✨ Características
🌌 Exploración de información sobre asteroides.
🛰️ Conexión con la API oficial de la NASA.
🌍 Información relacionada con objetos cercanos a la Tierra.
📡 Consulta de datos mediante JavaScript.
💻 Interfaz web interactiva.
